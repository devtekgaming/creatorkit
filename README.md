# CreatorKit

A simple static website with free creator tools.

## Included
- YouTube Title Generator
- Hashtag Generator
- Username Generator
- Word Counter

## Run locally
Open `index.html` directly in a browser, or upload the three website files to a static host.

## Ads
The `ADVERTISEMENT` boxes are placeholders. Replace them with the ad-network code after your site is approved. Do not click your own ads or encourage users to click them.

## Before applying for an ad network
Add real Privacy Policy, Terms, Contact and About pages, then publish useful original content and make sure the site follows the ad network's current policies.
